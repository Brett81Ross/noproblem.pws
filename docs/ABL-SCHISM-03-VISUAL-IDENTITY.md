# ABL-SCHISM-03 — Visual Identity

Status: DESIGN FOUNDATION
Production impact: NONE
Deployment authorized: NO
Parent branch: abl-schismmatrix-01-brand-foundation

## Brand lock

**SchismMatrix™**
**Property Intelligence**

SchismMatrix is a standalone CactusByte Studios product. The visual identity must communicate property intelligence and evidence-driven decision support without looking like an MCX operating-company logo or a generic pressure-washing brand.

## Design objectives

The identity should feel:

- intelligent, technical, precise;
- dark and slightly mysterious without becoming gothic;
- credible for contractors, property operators, and field professionals;
- recognizable at app-icon size;
- modern without generic "AI startup" visual clichés;
- distinct from RIVETEX and MCX while still belonging in the CactusByte ecosystem.

## Symbol concept territory

The mark should explore **controlled discontinuity**: a coherent form interrupted by a deliberate split, offset, fault, or divided data plane. The concept connects naturally to the word *schism* while also suggesting analysis: SchismMatrix identifies the meaningful break, difference, condition, or signal inside property evidence.

The symbol must work without the wordmark.

Avoid:

- literal cracked-house clip art;
- pressure-washer wands, spray guns, hoses, roofs, water droplets as the primary mark;
- obvious Matrix-movie/code-rain references;
- brains, robot heads, circuit-board clichés, sparkle-AI icons;
- music/band logos or TOOL-derived visual language;
- overly intricate geometry that dies at 32–48 px.

## Wordmark

Primary spelling: **SchismMatrix™**.

Customer-facing display may use uppercase styling, but the written brand remains one compound word.

Descriptor: **Property Intelligence**.

The descriptor is secondary and must remain legible without competing with the product name.

## Color direction — exploratory, not final

Start from the product's existing dark interface rather than forcing a complete UI recolor:

- near-black / deep blue-black foundation;
- cool white primary type;
- cyan/ice-blue signal accent.

Exact production color tokens are not locked in this ABL. Accessibility contrast must be checked before adoption.

## Required identity set

Before approval, produce and review:

1. primary symbol;
2. horizontal symbol + wordmark;
3. stacked lockup;
4. app icon;
5. favicon/small-size mark;
6. monochrome version;
7. dark-background version;
8. light-background version;
9. wordmark-only treatment;
10. minimum-size/clear-space guidance.

## Mobile/Fold requirement

The identity must be inspected at narrow phone widths and app-icon scale. The symbol cannot depend on tiny internal details. SchismMatrix must remain readable on the Galaxy Z Fold front display as well as conventional Android/iOS screens.

## Approval gate

No generated concept becomes the official logo merely because it looks good in one mockup.

Visual identity is LOCKED only after:

- symbol approved by Brett;
- wordmark relationship approved;
- small-size legibility checked;
- dark/light/monochrome behavior checked;
- no obvious third-party logo collision discovered in a reasonable visual/name review;
- implementation assets are prepared separately;
- explicit approval is given before production integration.

## Current temporary UI

The CSS SchismMatrix wordmark currently in the development branch is a placeholder presentation shell. It is not the permanent logo and should be replaced only after this visual identity ABL is approved.
